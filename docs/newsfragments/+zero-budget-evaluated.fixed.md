A zero iteration budget (`maxiter = 0`) now judges the start it was given. `Solver::run`, the `minimize_*` one-shots, `rgmin_minimize`, `rgmin_minimize_hess`, `rgmin_minimize_hvp`, `rgmin_minimize_eindir` and Python `minimize` evaluate `x` once, take no step, and report that value and gradient norm with `Tolerance` below `gtol`, `NoiseFloor` under the noise floor, else `Budget`. Before, `Solver::run` and Python `minimize` reported value 0 and gradient norm 0 (`Solver::run` with `Tolerance`) without an evaluation, and the FIRE, BB, QuickMin, ODE12r, DIIS, Newton-CG and dogleg one-shots reported `Budget` with an infinite gradient norm even at a stationary start. A positive budget also changed: `Solver::run` reports `Budget` instead of `Iterating` when it runs out, and `Solver::run` and those one-shots end on a step's `NoiseFloor` instead of stepping past it. The eOn CG report reads `converged` from the gradient it returns. `rgmin_minimize_scg` keeps `maxiter = 0` as no limit. The C signatures and ABI minor 43 are unchanged.
