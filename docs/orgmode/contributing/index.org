* Contributing

** Build

Never compile on a laptop. rsync the checkout to the remote builder
and run ~cargo test --features capi~ there. ~eindir-core~ is a
pinned git dependency.

** Citations

Narrative pages cite through ~sphinxcontrib-bibtex~ (~:cite:`key`~)
against ~docs/source/references.bib~. That file is the ~rgmin-docs~
ookcite collection (~export_collection~). Add a DOI with
~validate_doi~ then ~add_to_collection~; never edit the .bib, never
invent keys, never keep a markdown citation table. The rendered
list is [[file:../reference/bibliography.org][reference/bibliography]].

** Formulae

Nocedal-Wright equation numbers are the contract:

- NLCG is algorithm 5.4
- Inverse BFGS is 6.17
- L-BFGS two-loop is 7.4, scale is 7.20
- Strong Wolfe is 3.5 / 3.6
- Goldstein is 3.11
- Hager-Zhang beta is paper equation 1.3, not the C++ port

** Docs

Narrative docs live in ~docs/orgmode/~ (Diataxis: tutorials, howto,
reference). Export to RST with ~emacs --script docs/export.el~ from
~docs/~. The export needs Org 9.7 or newer from GNU ELPA: ox-rst
calls ~org-element-type-p~, which that release added, and the Emacs
on the docs runner ships Org 9.6. ~docs/export.el~ installs the ELPA
release and puts it ahead of the built-in Org. Sphinx (Shibuya)
reads ~docs/source/~; logos live in ~branding/logo/~ and are copied
into ~docs/source/_static/~.
The C ABI HTML is Doxygen plus doxyYoda; see
[[file:../howto/doxygen.org][howto/doxygen]].

Pull requests run the Org export and the Sphinx build. The Pages
deploy runs on a push to ~main~ whose paths touch ~docs/~ or the
workflow, and on ~workflow_dispatch~. A pull request has its own
concurrency group, so it does not cancel a deploy.

* Building the docs

Export the orgmode tree to rst with =emacs --batch -l docs/export.el=.
That script installs Org 9.7 or newer from GNU ELPA before ox-rst.
Then build =docs/source= with Sphinx. Pull requests run the export
and the Sphinx build; the Pages deploy does not. The build needs =shibuya=,
=myst-parser=, and =sphinxcontrib-bibtex=; the bibliography comes from
=docs/source/references.bib=, which is generated from the
=rgmin-docs= ookcite collection (=export_collection=), never edited by
hand. New citations enter through ookcite (=validate_doi= first, then
=add_to_collection=). Pages cite with =:cite:`key`=; Sphinx
renders them via =sphinxcontrib-bibtex=.
